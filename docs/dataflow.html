Isolated cadence/registry — a failure here only ever produces its own sync_runs row and leaves the last-good display_cache row in place; never affects the mirror registry.

run_cycle/run_all_due: per-resource isolation — one resource's failure rolls back only its own upsert, recorded on its own sync_runs row, and never blocks a sibling resource's cycle.

Work-order creation MES

app/sync/hooks.py (subscriber, wired at python -m app.sync startup only) → app/domain/workorders.py

  • order_line_item_new / order_line_item_changed → app/sync/hooks.py:_handle_line_item_event → app/domain/workorders.py:create_from_line_item
  • order_closed → app/sync/hooks.py:_handle_order_closed → app/domain/workorders.py:cancel_work_order for every work order under that order's line items
  • create_from_line_item calls app/domain/binding.py:bind_full_routing (op-code → work-center → fuzzy-title rungs, via app/domain/library.py:resolve_published) to resolve each routing step to a published InstructionSet, then freezes a full deep-copy of its steps/substeps into plan_operations.frozen_content — publishing a newer library version afterward never mutates it

Writes land in the same DB transaction as the mirror upsert that triggered them (hook receives the firing cycle's own, still-open session) — both commit or both roll back together.

writes work_orders, units, plan_operations (frozen plan) — Postgres

Write-back payload build + enqueue write-back

app/outbox/payloads.py → app/outbox/writer.py:enqueue

  • build_time_ticket_detail builds TimeTicketDetailCreate (employeeCode, jobNumber, stepNumber, workCenter, piecesFinished/Scrapped, reasonNumber, timeStart/End or setupTime) — resolves employee/job-number/work-center via the JB2 mirror; unmapped values record a mapping_exceptions row and skip the write (never enqueue garbage)
  • ensure_time_ticket_header enqueues one time_ticket header per (employee, date)
  • writer.enqueue inserts the jb2_outbox row in the caller's own transaction — same commit/rollback unit as the domain write that produced it

CR-010: time-ticket / time-ticket-detail write-backs are the sole JB2 write-back — OrderRoutingUpdate PATCH carries no actuals/status field, so there is no routing-step write-back path at all.

insert into jb2_outbox (status: pending)

jb2_outbox write-back

Postgres table — app/domain/models_jb2.py:JB2Outbox

FIFO per work_order_id (rows with a NULL work_order_id share one FIFO stream). Status lifecycle: pending → sent → confirmed | failed.

app/outbox/drainer.py:drain_once — per-stream FIFO drain, DEFAULT_SENDERS = {time_ticket → _send_time_ticket, time_ticket_detail → _send_time_ticket_detail}; exponential backoff to 8 attempts, 4xx parks immediately as failed (admin replay() via POST /admin/outbox/{id}/replay, app/api/health.py)

Events + live dashboard MES

app/domain/events.py → events table → app/api/dashboard.py → app/domain/pipeline.py

  • events table (Postgres, models_floor.py) — every scan.*/session.*/substep.*/failure.*/unit.*/box.*/wo.status_changed/outbox.enqueued/auth.*/backfill.recorded verb, per VALID_VERBS
  • GET /dashboard/stream (app/api/dashboard.py:dashboard_stream) polls SELECT max(id) FROM events every 1s and pushes an SSE refresh ping when it changes — client re-fetches GET /api/v1/dashboard/pipeline
  • app/domain/pipeline.py:build_board/compute_kpis/group_cards derive the 7-state board (blocked_no_instructions > overdue > stalled > rework > in_transit > queued > first_pass) from units/work_orders/plan_operations/work_sessions/failures/transits — no new table
▨ Not used for this: app/ws/hub.py (in-process publish()/subscribe()) exists per the original task shape but is deliberately not wired into events.emit() — an in-process queue can't cross the 4 uvicorn workers (CR-015). The dashboard's live update is the DB-poll-then-SSE path above, correct across however many workers run; hub.py is dead code kept for a possible future single-process/dev use.
on-demand admin actions render execution + library state to PDF via WeasyPrint — no background job, generated the moment a route is hit
